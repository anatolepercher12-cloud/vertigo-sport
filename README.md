# Vertigo Sport — site web

Site vitrine et services en ligne de Vertigo Sport (6 magasins en Pays de la Loire), réalisé par DigitalCraft d'après le dossier de cadrage MOA (carte B, v2).

- Catalogue avec prix et stock par magasin (données de démonstration dans `assets/data.js`)
- Une page par magasin (référencement local), sitemap et robots.txt
- Réservation de matériel de location, retrait et paiement en magasin
- Espace client (favoris, réservations, suppression du compte) — démo stockée dans le navigateur
- Blog, contact, mentions légales, politique de confidentialité, bandeau cookies conforme CNIL

Site statique : ouvrir `index.html` ou publier avec GitHub Pages.
